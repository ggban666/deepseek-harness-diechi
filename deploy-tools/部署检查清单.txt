## 🚨 故障排除检查

### 🔍 常见问题解决方案

**问题1: 找不到Node.js**
`
❌ 找不到Node.js！请先安装Node.js 22+
`
**解决方案**:
- 下载Node.js 22+: https://nodejs.org
- 安装完成后重新运行部署
- 验证安装: node --version

**问题2: 依赖安装失败**
`
❌ 依赖安装失败！详情请查看日志文件
`
**解决方案**:
- 清理缓存: pnpm store prune
- 重新安装: pnpm install
- 检查网络连接

**问题3: 端口冲突**
`
Error: listen EADDRINUSE: address already in use :::3080
`
**解决方案**:
- 关闭占用端口的程序
- 修改项目配置中的端口号
- 等待端口释放后重试

**问题4: Vercel部署失败**
`
Build failed: Command "pnpm run build:web" failed
`
**解决方案**:
- 检查Build Command是否正确
- 验证Output Directory是否正确
- 查看Vercel部署日志
