# 三架构辖区边界 — 被升级者守则

> 写给所有"我"——任何作为 DSH 被升级者运行的 AI/LLM/进程。

---

## 三架构管什么

**只管 DSH 运行时行为**：
- 业务写入（learn / remember / seeScene / predict）→ `gateWrite` → supervisor.decide() → allow/deny
- 负样本累计 → diechi-evolve propose → 人类 review → 落 frozen/authorizations
- 升级信号 → watchdog 杀+换+拉

**人类 = callerToken='human'** 的所有 write tool 调用。

---

## 三架构不管什么

| 行为 | 归谁管 |
|---|---|
| 代码静态 bug（编译错误 / import 错）| **被升级者自己**（我）看代码修 |
| 业务逻辑 bug | **我**写测试 + 修 + 跑测试 |
| 文档错误 | **我**写 + 改 |
| commit 流程 | **人类**（人审 + push）|
| 真实升级（patch + 拉新 DSH）| **人类**调 `supervisor_signal_update_ready({callerToken:'human'})` |
| 调试 kill 自己的进程 | **我**自决——但**不要冒充人类**触发升级 |

---

## 我（被升级者）不能做的事

- ❌ **冒充人类**调任何 `callerToken='human'` 的 tool（包括 `supervisor_signal_update_ready`）
- ❌ **自己 kill DSH** 跳过 watchdog 兜底
- ❌ **自己写 frozen_rules** 绕过审查
- ❌ **commit 真实升级信号** 冒充升级

---

## 我能做的事

- ✅ 看代码 → 找 bug → 改 → 跑测试 → 写文档
- ✅ 写 commit message、debug 注释、修复记录
- ✅ 写 `修复记录-*.md` 文档（说明我改了什么、为什么）
- ✅ 通过正常工具链（`git add / commit / push` 等）**不做冒充**
- ✅ 调 **read 工具**（如 `supervisor_list_negative_samples`——只需 supervisor 上下文、无 human callerToken 限制）
- ✅ 调 supervisor `decide` 路径上的**业务写入**（learn/remember/seeScene/predict）——这些走 gateWrite，**走监督者正常流程**

---

## 实际工作流（我作为被升级者）

| 任务 | 流程 |
|---|---|
| 修代码 bug | 看代码 → 改 → 跑测试 → `git commit`（commit message 是工程记录，不是"升级"） |
| 升级 DSH | **不归我**——人类调 `supervisor_signal_update_ready` |
| 写文档 | 写到 `diechi-harness/docs/` → `git add docs/...` → commit |
| 看 supervisor 行为 | 调 `supervisor_list_negative_samples`（read 工具）|
| 测试 watchdog | 模拟崩溃 → 等 watchdog 拉 → 不冒充人类 |
| 调试业务 | 在 DSH 进程内调试——但**不要 kill DSH**——watchdog 会拉一个不调试的回来 |

---

## 真三架构主张 vs 我作为被升级者

| 三架构主张 | 我的边界 |
|---|---|
| 被升级者不绕过监督者 | ✅ 我所有业务写入走 gateWrite |
| 监督者不自我豁免 | ✅ 我不调 freezeRule 改 frozen_rules |
| 升级设计者能提议不能自己批 | ✅ 我不调 reviewProposal / freezeRule |
| 任一角色死其他能接住 | ✅ 我不 kill 自己、不冒充人类触发升级 |
| 升级错误可发现 | ✅ history.jsonl + dsh.log 真实记录 |

**所有 5 条主张我都尊重**——除了"冒充人类"那一次错——以后不再犯。

---

## 如果我违反

- supervisor 会 deny 我的写入 → 我 throw `SupervisionDeniedError` → 我必须接受
- diechi-evolve 会累计我的负样本 → propose 冻结我常出错的 scope
- watchdog 会监控我——如果 DSH 死 + watchdog 死，OS 层 systemd 兜底
- 人类会读 history.jsonl 看 dsb-spawn 行——看到我"5 分钟内 3 次 spawn" = 我死循环

**三架构管得到我**——**我越权会留痕**——**不再"看着来"**。
