DIECHI · 三架构自进化基座

把智能从模型里搬出来，放进架构里

一个弱智 LLM，只要放进被升级者 + 升级设计者 + 监督者的结构里并给予足够算力， 系统的表现可以趋近任意强——
因为它不再依赖单次采样猜对，而依赖 多猜几次 + 判定对错 + 把猜对的永久固化。

C(N) = 1 − (1 − p)N C = 一次通过率 · p = 模型单次采样正确率（可以很弱）· N = 有效算力

1三条设计公理

后面所有工程决策都由这三条推导。任何与之冲突的实现都是 bug。

AXIOM A1

单调性 · 能力只升不降

任何改动先过回归门：新版本在冻结基准集上不劣于旧版本才允许合并。禁止"删除式改进"，固化库只增不减，删除 = 标记 superseded，永不物理丢弃。

AXIOM A2

有界性 · 成本 ±20%

智能的增长不许靠无限烧钱换。成本必须落在滑动基线 K̄ 的 ±20% 软带内，且有 绝对硬顶 Kmax（防棘轮式缓慢爬升）。超带 → 降档，超顶 → 拒绝服务。

AXIOM A3

可判定性 · 判定确定性

判定比生成容易，且判定必须是确定性的。监督者 decide() 是查表、不调 LLM——这条已在代码里做到了，是整个体系的地基，不可动摇。

固化：让曲线真正向上的物理机制

纯靠算力放大 N 有个致命问题：成本随 N 线性上升，而且每次都要重新蒙。 解药是固化——每次蒙对的结果转成规则 / 案例 / 技能，下次直接命中，不必再采样。

C(t) = C₀ + Σ ΔCᵢ　（ΔCᵢ ≥ 0，永不撤销）
K(t) = 采样成本(N) + 检索成本(|规则库|)

采样的收益是一次性的，固化的收益是永久性的。 固化率越高，所需 N 越小 → 越容易守住成本带。进化和省钱是同一件事。

诚实的边界（不许自我欺骗）

可靠性闭环（自愈/升级/降级/基座保护）已端到端实证
进化闭环从未运转
验证器可靠 + 任务可判定 ⟹ C → 1可证伪推论
三架构是 AGI 的充分条件主张，非定理

A3 破产的三种情况必须显式检测并报警：
① 任务没有客观对错（审美/价值观）→ 验证器不可靠
② 任务分布漂移 → 历史固化反而成为负债
③ 提议空间不含解 → 算力再多也不收敛，需 human 注入新原语

    3三架构闭环与双门

    光点沿环路流动：正/负样本 → 监督者判定 → 升级设计者出提议 → 沙盒评估 → 双门 → 合并回被升级者。双门处有通过 / 拦截的分叉。

    这条公式的三个前提

    缺任何一个，放大律都不成立：

    ① 采样独立否则 (1−p)^N 不成立
    ② 验证器无误判A3，监督者查表保证
