## 🚀 部署步骤

### 步骤1: 创建GitHub仓库 (15分钟)

**操作**:
1. 访问 https://github.com/new
2. 命名: diechi-app
3. 选择Public或Private
4. 点击Create repository

**验证**:
- 仓库创建成功
- README.md文件显示

### 步骤2: 配置Vercel项目 (30分钟)

**操作**:
1. 登录 https://vercel.com
2. 点击Add New → Project
3. 选择GitHub仓库 diechi-app
4. 配置:
   - Build Command: pnpm run build:web
   - Output Directory: apps/web/dist
   - Install Command: pnpm install
5. 添加环境变量:
   - NODE_ENV=production
   - PORT=3000
6. 点击Deploy

**验证**:
- 部署成功
- 应用在 https://diechi-app.vercel.app 正常运行

### 步骤3: Docker容器部署 (45分钟)

**操作**:
`ash
cd D:\桌面\振翅科技\蝶翅-app

# 构建镜像
docker build -t diechi-app:latest .

# 运行容器
docker run -d --name diechi-app -p 3000:3000 -e NODE_ENV=production diechi-app:latest

# 推送到Docker Hub
docker login
docker tag diechi-app:latest yourusername/diechi-app:latest
docker push yourusername/diechi-app:latest
`

**验证**:
- 镜像构建成功
- 容器运行正常
- 镜像推送成功

### 步骤4: 配置CI/CD自动化 (60分钟)

**操作**:
1. 创建 .github/workflows/deploy.yml
2. 添加GitHub Actions配置
3. 配置Secrets:
   - VERCEL_TOKEN
   - VERCEL_ORG_ID
   - VERCEL_PROJECT_ID
4. 推送代码到GitHub

**验证**:
- GitHub Actions流水线自动触发
- 构建、测试、部署自动化
