🚀 立即开始部署 (3步完成)

步骤1: 创建GitHub仓库 ⏱️ 15分钟
----------------------------------

📌 操作:
1. 打开浏览器，访问 https://github.com/new
2. 填写仓库名称: diechi-app
3. 选择Public或Private
4. 点击 "Create repository"

📌 验证:
- [ ] 仓库创建成功
- [ ] README.md显示在GitHub上

📌 命令行操作 (可选):
`ash
cd D:\桌面\振翅科技\蝶翅-app
git init
git remote add origin https://github.com/your-username/diechi-app.git
git add .
git commit -m "Initial commit: 蝶翅APP v1.0 [skip ci]"
git push -u origin main
`

---

步骤2: 部署到Vercel ⏱️ 30分钟
--------------------------------

📌 操作:
1. 访问 https://vercel.com/signup (注册账户)
2. 登录后，点击 "Add New" → "Project"
3. 选择GitHub仓库: diechi-app
4. Vercel会自动检测项目
5. 配置部署选项:
   - Build Command: pnpm run build:web
   - Output Directory: apps/web/dist
   - Install Command: pnpm install
6. 添加环境变量:
   - NODE_ENV=production
   - PORT=3000
7. 点击 "Deploy"

📌 验证:
- [ ] 部署开始 (状态: Queued → Building → Ready)
- [ ] 点击 "Visit" 按钮访问应用
- [ ] 应用在 https://diechi-app.vercel.app 正常运行

---

步骤3: 测试应用功能 ⏱️ 10分钟
---------------------------------

📌 操作:
1. 访问部署的应用地址
2. 测试以下功能:
   - 专家角色切换 (尝试不同的专家)
   - 对话界面流式输出
   - 本地存储功能
   - 响应式设计 (调整浏览器窗口大小)

📌 验证清单:
- [ ] 应用界面正常加载 (< 2秒)
- [ ] 7个专家角色都能正常切换
- [ ] 对话功能正常工作
- [ ] 无浏览器控制台错误
