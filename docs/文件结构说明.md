## 📊 项目信息

### 🎯 蝶翅APP核心功能

- **7个专家角色**: SQE、法律、HR、客服、写作、代码审查、财务
- **专家切换**: 一键切换专家角色
- **对话界面**: 流式输出，消息历史记录
- **技术面板**: 可隐藏的技术细节面板
- **响应式设计**: 支持桌面、平板、移动端

### 🔧 技术栈

- **前端**: React 18 + TypeScript + Vite 5
- **状态管理**: Cordis (DeepSeek Harness核心)
- **包管理**: pnpm
- **构建工具**: Vite 5
- **部署**: Web + Docker + CI/CD
