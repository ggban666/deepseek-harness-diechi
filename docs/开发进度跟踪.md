## 🔧 视觉+语音服务（D:\vision-server.py，端口 8080）

```powershell
# 手动启动（启动器会自动拉起，无需手动）
& D:\vllm-env\Scripts\python.exe D:\vision-server.py 8080
# 健康检查
Invoke-RestMethod http://127.0.0.1:8080/health
```

- `GET /health`：模型加载状态与显存
- `POST /v1/chat/completions`：OpenAI 兼容，图片识别（`image_url` data URL），前端「识别图片」走这里
- `POST /api/v1/video/describe`：multipart 上传原视频 → 服务端解码 → 模型原生视频理解 → 技能草稿 JSON
- `POST /api/v1/tts`：Kokoro 中文 TTS（`{text, voice, speed}` → wav），音色 zf_001/zf_018/zm_010/zm_016

环境：Python venv 在 `D:\vllm-env`（纯 ASCII 路径，tvm-ffi 的 C++ 在中文路径下必崩，勿移回中文目录）；transformers 5.15.0 打了 `vit_merger` 变长帧补丁；模型在 `models\MiniCPM-V-4.6`（官方权重）+ `models\kokoro-zh`（ONNX 324MB + 4 音色）。
