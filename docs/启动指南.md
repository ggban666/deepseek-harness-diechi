## 🔧 技术架构

### DeepSeek Harness
- **框架**: Cordis (DeepSeek官方框架)
- **启动命令**: `pnpm dsh web`
- **端口**: 3080
- **作用**: AI工作台核心引擎

### 蝶翅APP前端
- **框架**: React 18 + TypeScript + Vite 5
- **启动命令**: `pnpm --filter @diechi/web run dev`
- **端口**: 3000
- **作用**: 用户界面和AI交互界面

## 🐛 常见问题解决

### Q1: 访问localhost:3000显示连接被拒绝？
**原因**: 前端服务没有启动或端口冲突

**解决方案**:
1. 运行 `故障排除.bat` 检查依赖
2. 确保没有其他程序占用端口3000
3. 手动启动: `cd D:\桌面\振翅新科\蝶翅-app && pnpm --filter @diechi/web run dev`

### Q2: 找不到Node.js？
**解决方案**:
1. 下载安装Node.js 22+: https://nodejs.org/
2. 重新运行故障排除工具

### Q3: 找不到pnpm？
**解决方案**:
1. 运行: `npm install -g pnpm`
2. 重新运行故障排除工具

### Q4: 依赖安装失败？
**解决方案**:
1. 删除 `node_modules` 文件夹
2. 重新运行 `故障排除.bat`
3. 如仍然失败，检查网络连接
