- **框架**: DeepSeek Harness / Cordis
- **启动命令**: `pnpm dsh web --port 3090`（必须设置 `DSH_HOME`）
- **端口**: 3090
- **作用**: 蝶翅用户界面、技能、模型和对话工作台

## 🐛 常见问题解决

### Q1: 访问127.0.0.1:3090显示连接被拒绝？
**原因**: 蝶翅 Harness 服务没有启动或端口冲突

**解决方案**:
1. 使用 `蝶翅APP启动器.exe` 或 `deploy-tools\start-diechi.cmd` 启动
2. 确保没有其他程序占用端口3090
3. 健康检查: `irm http://127.0.0.1:3090`

### Q2: 找不到Node.js？
**解决方案**:
1. 下载安装Node.js 22+: https://nodejs.org/
2. 重新运行故障排除工具

### Q3: 找不到pnpm？
**解决方案**:
1. 运行: `npm install -g pnpm`
2. 重新运行故障排除工具

### Q4: 依赖安装失败？
**解决方案**:
1. 删除 `node_modules` 文件夹
2. 重新运行 `故障排除.bat`
3. 如仍然失败，检查网络连接
