=== 蝶翅APP与DeepSeek Harness集成方案 ===

🎯 核心目标: 让蝶翅专家角色能在DeepSeek原生对话界面使用

📋 集成步骤:

1. ✅ 技能文件复制
   - 将蝶翅专家角色配置复制到外层DeepSeek Harness
   - 位置: deepseek-harness-master/diechi-skills/
   - 包含4个专家角色: sqe-8d, legal-consult, customer-service, hr-management
2. 🔧 配置更新
   - DeepSeek Harness会自动识别diechi-skills目录中的技能
   - 技能选择后在原生对话界面生效

3. 🚀 使用方法

方法1: 直接使用外层Harness
   - 访问: http://127.0.0.1:3080
   - 在技能选择面板中选择'蝶翅-*'开头的角色
   - 开始与专家对话

方法2: 通过启动器切换
   - 使用: 蝶翅APP启动器.cmd
   - 选择选项4: 启动原版Harness (端口3080)
   - 选择选项6: 访问原版Harness

4. 🎨 蝶翅APP仍然独立运行
   - 端口: 3090
   - 位置: 蝶翅-app/diechi-harness
   - 保持所有v2.0预览版功能
✅ 集成完成！现在可以在DeepSeek原生界面使用蝶翅专家角色了！
