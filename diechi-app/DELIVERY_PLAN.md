### **📌 2.1 系统部署**

#### **🚀 生产环境部署**

##### **前提条件**
```
✅ Docker 24.0+
✅ Docker Compose 2.0+
✅ 服务器资源：4核CPU、8GB内存、100GB存储
✅ 域名和SSL证书
✅ DeepSeek API密钥
✅ PostgreSQL数据库
✅ Redis缓存
✅ RabbitMQ消息队列
```

##### **部署步骤**

```bash
# 1. 登录服务器
ssh root@your-server-ip

# 2. 克隆项目
cd /opt
git clone https://github.com/vibechina/diechi-app.git
git checkout production

# 3. 配置环境变量
cd diechi-app
cp .env.example .env.production
code .env.production

# 必需配置项：
# DEEPSEEK_API_KEY=your-api-key
# POSTGRES_PASSWORD=your-postgres-password
# REDIS_PASSWORD=your-redis-password
# RABBITMQ_DEFAULT_USER=admin
# RABBITMQ_DEFAULT_PASS=admin
# DOMAIN_NAME=your-domain.com

# 4. 启动生产环境
bash scripts/prod-start.sh

# 5. 验证部署
curl https://your-domain.com/health

# 预期输出：
# {"status":"healthy","timestamp":"...","services":{"postgres":"ready","redis":"ready","rabbitmq":"ready"}}
```

##### **域名配置**
```
# 1. 配置DNS记录
# 类型: A记录
# 主机: @
# 值: your-server-ip

# 2. 配置Nginx反向代理
# 编辑 /etc/nginx/conf.d/diechi-app.conf

server {
    listen 80;
    server_name your-domain.com;
    
    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# 3. 配置SSL证书
# 使用Let's Encrypt获取免费SSL证书
certbot --nginx -d your-domain.com

# 4. 重启Nginx
systemctl restart nginx
```

#### **🔄 备份脚本**

```bash
#!/bin/bash
# 数据库备份脚本
# 保存为 scripts/backup-database.sh

# 配置
DB_HOST="localhost"
DB_PORT="5432"
DB_NAME="diechi"
DB_USER="postgres"
DB_PASSWORD="your-password"
BACKUP_DIR="/opt/backups/postgres"
DATE=$(date +"%Y%m%d_%H%M%S")

# 创建备份目录
mkdir -p "$BACKUP_DIR"

# 备份数据库
pg_dump -h "$DB_HOST" -p "$DB_PORT" -U "$DB_USER" -d "$DB_NAME" -F c -f "$BACKUP_DIR/diechi_$DATE.dump"

# 压缩备份
gzip "$BACKUP_DIR/diechi_$DATE.dump"

# 清理30天前的备份
find "$BACKUP_DIR" -name "diechi_*.gz" -mtime +30 -delete

echo "数据库备份完成: $BACKUP_DIR/diechi_$DATE.dump.gz"
```

#### **🔙 恢复步骤**

```bash
# 1. 从备份文件恢复数据库
# 保存为 scripts/restore-database.sh

# 配置
DB_HOST="localhost"
DB_PORT="5432"
DB_NAME="diechi"
DB_USER="postgres"
DB_PASSWORD="your-password"
BACKUP_FILE="/opt/backups/postgres/diechi_20240315_020000.dump.gz"

# 解压备份文件
gunzip "$BACKUP_FILE"

# 恢复数据库
```
